Load a KML or KMZ — click, or drop the file here
Google’s key list runs to hundreds of entries and only one of them works here: enable Map Tiles API (console.cloud.google.com → APIs & Services), with billing on. A key that works for Maps JavaScript, Static Maps or Geocoding is still rejected by this one. No key at all is fine — you get keyless ESRI satellite, which is flat 2D drape with no building geometry. Keys are remembered on this device.
